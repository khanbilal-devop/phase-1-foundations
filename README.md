## Block 1 — Linear Algebra (Completed)
 
Three weeks covering the math foundation of ML: vectors, matrices, and matrix decompositions.
 
### Weekly summaries
 
- **Week 1 — Vectors** → [week-01-vectors/week-01-summary.ipynb](week-01-vectors/week-01-summary.ipynb)
- **Week 2 — Matrices** → [week-02-matrices/week-02-summary.ipynb](week-02-matrices/week-02-summary.ipynb)
- **Week 3 — Matrix Decompositions** → [week-03-decompositions/week-03-summary.ipynb](week-03-decompositions/week-03-summary.ipynb)
### Key concepts covered
 
Vector operations, dot product, cosine similarity, norms (L1/L2/L∞), span, linear independence, basis, rank, matrix multiplication, identity/inverse/determinant, solving linear systems, eigenvalues and eigenvectors, eigendecomposition, spectral theorem, singular value decomposition (SVD), low-rank approximation, Eckart-Young theorem.
